# 🌺 Onam Arcade

### 🎮 Experience Onam Through Interactive Games

**Onam Arcade** is a collection of interactive mini-games inspired by
the traditions, culture, colours, and festive spirit of **Onam**,
Kerala’s harvest festival.

The project transforms familiar elements of Onam into engaging
arcade-style experiences where players can test their **memory,
reflexes, timing, and accuracy**.

🔗 **Live Game:** https://onamgame-l1w4r85w7-avani16.vercel.app/

------------------------------------------------------------------------

## 🎮 Games

Onam Arcade currently features three unique Onam-inspired games:

### 🧠 Pookalam Master

A memory and accuracy challenge based on the traditional **Pookalam**.

Players first study a Pookalam design. Once the reference disappears,
they must recreate the design from memory.

#### Features

- 🌺 Recreate Pookalam designs from memory
- 🧠 Memory-based gameplay
- ⏱️ Time-based challenge
- 🎯 Accuracy-based scoring
- ❤️ Limited lives and attempts
- 🏆 Multiple difficulty levels

#### Difficulty Levels

| Level      | Rings | Difficulty |
|------------|------:|------------|
| 🌱 Novice  |     2 | Easy       |
| 🌿 Adept   |     3 | Medium     |
| 🌳 Vaidika |     4 | Hard       |

------------------------------------------------------------------------

### 🚣 Vallam Kali Sprint

Experience the excitement of Kerala’s traditional **Vallam Kali** snake
boat races.

Players control a boat racing down the river while avoiding obstacles
and collecting items for points.

#### Features

- 🚣 Lane-based boat movement
- 🪨 Dodge obstacles
- 🪔 Collect lamps
- 🌸 Collect flowers
- ❤️ Life system
- 📈 Increasing speed
- 🏆 Distance and score tracking

#### Controls

**Keyboard**

``` text
← Left Arrow
→ Right Arrow
```

**Mobile**

Use the on-screen/touch controls provided by the game.

The challenge becomes harder as the race progresses.

------------------------------------------------------------------------

### 🪔 Thumbi Taal

A rhythm-based game inspired by the festive atmosphere of Kerala.

Players must time their actions correctly with the rhythm and target
zone to maintain their performance and build a higher score.

#### Features

- 🪔 Rhythm-based gameplay
- 💃 Timing challenges
- 🎯 Accuracy-based hits
- 🔥 Combo system
- ❤️ Life system
- 📈 Increasing difficulty
- 🏆 Score tracking

#### Controls

``` text
Spacebar
```

or use the touch interaction provided by the game.

The better your timing, the longer you can maintain your combo.

# ✨ Key Features

### 🎮 Multiple Game Experiences

Onam Arcade combines three different gameplay styles instead of limiting
the project to a single mini-game.

### 🌺 Kerala-Inspired Design

The visual experience is inspired by the colours, traditions, symbols,
and festive atmosphere associated with Onam.

### 🧠 Skill-Based Gameplay

Each game focuses on a different skill:

- Memory
- Reflexes
- Timing
- Accuracy
- Concentration

### ❤️ Life System

Players need to balance speed and accuracy because mistakes can reduce
available lives.

### 🏆 Score-Based Challenges

Players can replay the games and try to improve their performance and
scores.

### 📈 Progressive Difficulty

The challenges become more demanding as the player progresses, keeping
the gameplay engaging.

### 📱 Responsive Interaction

The project supports desktop gameplay and touch-friendly interaction
where applicable.

# 💡 Concept

The concept behind Onam Arcade is to turn Kerala’s cultural traditions
into an interactive gaming experience.

Instead of simply presenting information about Onam, the project allows
players to **experience different elements of the celebration through
gameplay**.

The three games focus on different aspects of the Onam experience:

``` text
                         🌴 ONAM

         Memory         Reflexes        Timing

            └──────────────┼──────────────┘

                     🎮 ONAM ARCADE
```

# 🎯 Objective

The main objective of Onam Arcade is to combine:

**Kerala Culture + Gaming + Creativity + Technology**

The project aims to provide a modern, interactive, and entertaining way
to experience elements of Onam while introducing traditional Kerala
themes to players through games.

------------------------------------------------------------------------

# 🌴 Cultural Inspiration

Onam is one of Kerala’s most celebrated festivals and is associated with
traditions such as:

- 🌺 Pookalam
- 🚣 Vallam Kali
- 👑 King Mahabali / Maveli
- 🪔 Festive celebrations
- 🎵 Music and rhythm
- 🌴 Kerala’s cultural heritage

Onam Arcade takes inspiration from these cultural elements and presents
them in a modern game format.

------------------------------------------------------------------------

# 🏗️ Development Approach

The project was designed as a browser-based arcade experience with a
focus on:

1.  **Simple controls** — Players should be able to understand the games
    quickly.
2.  **Interactive gameplay** — Every game should require active player
    participation.
3.  **Progressive challenge** — Difficulty should increase as players
    improve.
4.  **Visual feedback** — Animations, scores, lives, and effects help
    communicate gameplay events.
5.  **Cultural identity** — The visual style and game concepts are
    connected to Kerala and Onam.
